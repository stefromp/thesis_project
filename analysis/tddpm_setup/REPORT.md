# Budget-matched GNN runs: does TabDDPM's training setup close the gap?

_Generated by `compare_setup.py`. **Targeted check, not a full re-run**: fixed rule only, five datasets (held-out cardio, house, king; development gesture, california; higgs-small and miniboone only if submitted). n is small; per-dataset results are descriptive. default is excluded (local data differs from the authors')._

budget-matched = the same GNN configuration, cat_input, seeds, EMA, sampling size and CatBoost config as the current run, trained with the authors' lr / steps / batch size / num_timesteps / scheduler (`--train_setup tabddpm`). TabDDPM and Real = the authors' `exp/<ds>/ddpm_cb_best/eval_catboost.json`. z = Δ / √(sd₁² + sd₂²) over the 50 runs; tie if |z| < 1. The 50 runs are 5 clusters of 10, so z overstates precision; it is a scale, not a test.
